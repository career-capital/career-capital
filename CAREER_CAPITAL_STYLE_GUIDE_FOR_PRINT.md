### Typography Best Practices

**For Presentations:**
- Maximum 6-7 words per line for readability
- No more than 6 lines of body text per slide
- Use 1.5-1.6 line height for body text
- Maintain consistent alignment (left-aligned for body, centered for titles)
- Allow generous white space (40-50% of slide)

**For Print:**
- Optimal line length: 50-75 characters (10-12 words)
- Use 1.5-1.7 line height for body text
- Add extra space between paragraphs (0.75-1em)
- Maintain margins: minimum 0.75" on all sides
- Use widows/orphans control (minimum 2 lines)

**General Rules:**
- Never use more than 2 font families in one design
- Limit font weights to 3 per design (e.g., Regular, Semi-Bold, Bold)
- Maintain clear hierarchy through size and weight differences
- Use uppercase sparingly (increase letter spacing to 0.05em when used)

### Color Usage Guidelines

**For Presentations:**

**Light Backgrounds** (recommended for most slides):
- Background: True White (#FFFFFF) or Bright Snow (#F8F9FA)
- Titles: Deep Space Blue (#0F2A44)
- Body text: Charcoal Blue (#4B5563)
- Accents: Baltic Blue (#2F5D8A)

**Dark Backgrounds** (use sparingly for impact):
- Background: Deep Space Blue (#0F2A44)
- Titles: True White (#FFFFFF)
- Body text: Bright Snow (#F8F9FA) or Surface (#E6E9EE)
- Accents: Baltic Blue (#2F5D8A) or Surface (#E6E9EE)

**Print Materials:**
- Use Deep Space Blue (#0F2A44) for headers and brand elements
- Use Charcoal Blue (#4B5563) for body text (better ink economy than pure black)
- Avoid using Baltic Blue for large areas (expensive to print)
- Use Bright Snow (#F8F9FA) instead of True White for softer pages

### Color Combinations

**High Contrast (Maximum Readability):**
- Deep Space Blue (#0F2A44) on True White (#FFFFFF)
- True White (#FFFFFF) on Deep Space Blue (#0F2A44)
- Carbon Black (#1A1A1A) on True White (#FFFFFF)

**Medium Contrast (Standard Use):**
- Charcoal Blue (#4B5563) on True White (#FFFFFF) - body text
- Baltic Blue (#2F5D8A) on True White (#FFFFFF) - links, accents
- Bright Snow (#F8F9FA) on Deep Space Blue (#0F2A44)

**Avoid These Combinations:**
- Charcoal Blue on Surface (insufficient contrast)
- Baltic Blue on Deep Space Blue (poor visibility)
- Any text on Pale Slate (contrast failure)

## Layout & Spacing

### Slide Layouts (16:9 Format)

**Standard Margins:**
- Top: 80-100px
- Bottom: 80-100px
- Left: 100-120px
- Right: 100-120px

**Content Area:**
- Maximum width: 85% of slide width
- Center important content vertically and horizontally
- Leave 40-50% white space per slide

**Grid System:**
- 12-column grid
- Gutter: 40px
- Use 2-3 column layouts for text-heavy slides
- Use 1 column for simple, impactful messages

### Print Layouts

**Letter/A4 Documents:**
- Margins: 0.75" - 1" all sides (minimum)
- Optimal line length: 4-6 inches (50-75 characters)
- Column width: 3-4 inches for single column
- Multi-column: 2.5-3 inches per column with 0.25" gutter

**Business Cards (3.5" × 2"):**
- Safe zone: 0.125" from all edges
- Bleed: 0.125" beyond trim line
- Keep text 0.25" from edges

### Spacing Scale (8px Base Unit)

| Size | Value | Usage |
|------|-------|-------|
| XXS | 4px | Minimal spacing, tight elements |
| XS | 8px | Related elements, tight groups |
| S | 16px | Default element spacing |
| M | 24px | Between sections within a component |
| L | 32px | Between related components |
| XL | 48px | Between major sections |
| XXL | 64px | Between page sections |
| XXXL | 96px | Major section breaks |

**Slides:**
- Title to body: 48-64px
- Between bullet points: 24-32px
- Between paragraphs: 32-40px
- Image to caption: 16-24px

**Print:**
- Heading to body: 12-16pt
- Between paragraphs: 8-12pt
- Between sections: 24-36pt
- Caption to next element: 8-12pt

## Visual Elements

### Logos

**Primary Logo:**
- Wordmark: "CAREER CAPITAL" in Space Grotesk
- Weight: Semi-Bold (600)
- Letter spacing: 0.05em (5% tracking)
- Color: Deep Space Blue (#0F2A44) on light backgrounds
- Color: True White (#FFFFFF) on dark backgrounds

**Clear Space:**
- Minimum clear space: Height of letter "C" on all sides
- Never place logo on busy backgrounds
- Minimum size: 0.75" width (print), 200px width (digital)

### Icons

**Source:** Lucide React icon library (lucide.dev)

**Sizing:**
- Small: 20-24px (presentations), 12-14pt (print)
- Medium: 32-40px (presentations), 16-18pt (print)

**Colors:**
- Primary: Baltic Blue (#2F5D8A)

- On dark: True White (#FFFFFF)

**Usage:**
- Use line icons (stroke-based) for consistency
- Maintain 2px stroke width for all icons
- Align icons optically, not mathematically
- Pair with text using 8-12px spacing

## Slide Templates

### Title Slide

**Layout:**
- Main title: 72pt Space Grotesk Bold, Deep Space Blue
- Subtitle: 36pt Inter Regular, Charcoal Blue
- Logo: Bottom right corner
- Background: Bright Snow (#F8F9FA) or branded hero image

**Spacing:**
- Title: Center vertically, 120px from top
- Subtitle: 64px below title
- Logo: 60px from bottom, 80px from right

### Content Slide (Standard)

**Layout:**
- Section header: 48pt Space Grotesk Semi-Bold, Deep Space Blue
- Body text: 28pt Inter Regular, Charcoal Blue
- 4-6 bullet points maximum
- Left-aligned content

**Spacing:**
- Header: 100px from top
- Body: 56px below header
- Between bullets: 28px
- Maximum 60% of slide width for text

### Section Divider

**Layout:**
- Large section title: 60-72pt Space Grotesk Bold
- Centered on slide
- Optional: Horizontal line above or below (2px, Baltic Blue)
- Minimal additional content

**Background Options:**
1. Deep Space Blue with white text
2. True White with navy text
3. Subtle branded image with overlay

### Quote Slide

**Layout:**
- Quote: 36pt Inter Regular Italic, Charcoal Blue
- Use opening/closing quotation marks
- Attribution: 24pt Inter Medium, below quote
- Plenty of white space

**Styling:**
- Center quote vertically and horizontally
- Maximum 3 lines of text
- Add subtle line accent above attribution (Baltic Blue)

### Two-Column Slide

**Layout:**
- Header: 48pt Space Grotesk Semi-Bold
- Two equal columns with 60px gutter
- Each column: 28pt Inter Regular
- Optional: Small headers within columns (32pt Space Grotesk Medium)

**Best for:**
- Comparisons
- Before/After
- Pros/Cons
- Side-by-side content

### Image + Text Slide

**Layout:**
- Image: 55% of slide width
- Text: 40% of slide width (5% gutter)
- Header: 42pt Space Grotesk Semi-Bold
- Body: 24pt Inter Regular

**Image Placement:**
- Left or right side
- Full height or 2/3 height
- Ensure proper image quality (300 DPI for print, 1920px+ for slides)

### Closing/Thank You Slide

**Layout:**
- Main message: 60pt Space Grotesk Bold, centered
- Contact info: 24pt Inter Regular
- Email/website: 28pt Inter Medium, Baltic Blue
- Logo: Present but not dominant

## Print Material Specifications

### Business Documents

**Letterhead:**
- Paper: White or Bright Snow (#F8F9FA)
- Header: Logo + address (9pt Inter)
- Footer: Website + email (9pt Inter)
- Body: 11-12pt Inter, 1.6 line height

**Business Cards:**
- Orientation: Horizontal (3.5" × 2")
- Front: Name (14pt Space Grotesk), Title (10pt Space Grotesk), Logo
- Back: Contact details (9pt Inter) or clean with logo
- Paper: Matte finish, 16pt cardstock

**One-Pagers/Flyers:**
- Title: 36-42pt Space Grotesk Bold
- Sections: 24pt Space Grotesk Semi-Bold
- Body: 11-12pt Inter
- White space: 40% minimum

### Print Best Practices

1. **Color Management:**
   - Use CMYK color mode for all print files
   - Include color profiles
   - Request color proofs before full print run

2. **File Preparation:**
   - PDF/X-1a or PDF/X-4 format
   - Embed all fonts
   - Convert text to outlines if font embedding fails
   - 300 DPI minimum for all images

3. **Bleed & Trim:**
   - Add 0.125" bleed on all sides
   - Keep critical elements 0.25" from trim line
   - Include crop marks

4. **Typography:**
   - Minimum 8pt font size for body text
   - Minimum 6pt for disclaimers/fine print
   - Use black (K100) or rich black (C40 M30 Y30 K100) for body text
   - Never use pure black for large background areas

## Brand Voice Guidelines

### Tone Attributes

- **Professional** yet approachable
- **Clear** and confident
- **Empowering** without being prescriptive
- **Knowledgeable** but not academic
- **Warm** while maintaining credibility

### Writing Style

**Presentations:**
- Short, punchy phrases
- Active voice
- Parallel structure in lists
- Minimal punctuation
- Lead with the insight/benefit

**Print Materials:**
- Complete sentences
- Professional tone
- Support claims with evidence
- Clear calls to action
- Avoid jargon

### Messaging Hierarchy

1. **Headline** - The main benefit or insight (what they get)
2. **Subheading** - Supporting detail or context (why it matters)
3. **Body** - Explanation, process, or evidence (how it works)
4. **Call to Action** - Clear next step (what to do)
