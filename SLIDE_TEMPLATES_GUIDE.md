# Career Capital Slide Templates

This guide provides detailed specifications for creating presentation slides that match the Career Capital brand.

## Setup Your Presentation

### Slide Dimensions
- **Aspect Ratio:** 16:9 (Widescreen)
- **Dimensions:** 1920 × 1080 pixels (or 10" × 5.625")
- **Safe Zone:** Keep content 100px from edges

### Install Fonts
1. **Space Grotesk**: Download from [Google Fonts](https://fonts.google.com/specimen/Space+Grotesk)
2. **Inter**: Download from [Google Fonts](https://fonts.google.com/specimen/Inter)

### Color Palette Setup
Add these colors to your presentation's color palette:

| Swatch Name | Hex Code | RGB |
|-------------|----------|-----|
| Navy | #0F2A44 | R:15 G:42 B:68 |
| Steel | #2F5D8A | R:47 G:93 B:138 |
| Ink | #1A1A1A | R:26 G:26 B:26 |
| Slate | #4B5563 | R:75 G:85 B:99 |
| White | #FFFFFF | R:255 G:255 B:255 |

| Surface | #E6E9EE | R:230 G:233 B:238 |
| Border | #D1D5DB | R:209 G:213 B:219 |

## Animation Guidelines

### When to Use Animation
- Reveal content progressively (avoid overwhelming audience)
- Emphasize key points
- Show relationships or sequences
- Maintain audience attention

### Recommended Animations

**Entrance:**
- Fade In (duration: 0.3s)
- Appear (instant)
- Fly In from Left (duration: 0.4s, for lists)

**Emphasis:**
- Pulse (once, on click)
- Darken/Lighten (subtle color change)

**Exit:**
- Fade Out (duration: 0.3s)
- Disappear (instant)

### Animation Rules
- Keep animations subtle and professional
- Duration: 0.2-0.4 seconds maximum
- One animation per element
- Avoid bouncing, spinning, or "fun" effects
- Never auto-advance without user control
- Respect reduced motion preferences

## Quality Checklist

Before finalizing your presentation:

### Typography
- [ ] All headers use Space Grotesk
- [ ] All body text uses Inter
- [ ] Font sizes match specifications
- [ ] No more than 3 font weights used
- [ ] Text is left-aligned (not justified or centered for body)

### Colors
- [ ] Colors match brand palette exactly
- [ ] Text has sufficient contrast (4.5:1 minimum)
- [ ] Consistent use of Navy for headers
- [ ] Consistent use of Slate for body text

### Layout
- [ ] 100px margins maintained on all sides
- [ ] White space is 40-50% of each slide
- [ ] Maximum 6 lines of body text per slide
- [ ] Elements are properly aligned

### Images
- [ ] All images are high resolution (1920px+ wide)
- [ ] Images are relevant to content
- [ ] No stretched or distorted images
- [ ] Proper attribution if required

### Consistency
- [ ] All slides use same background color family
- [ ] Spacing is consistent between slides
- [ ] Bullet styles are uniform
- [ ] Transition effects are subtle and consistent

### Accessibility
- [ ] Color is not the only way information is conveyed
- [ ] Alt text added to all images
- [ ] Animations can be disabled
- [ ] Reading order is logical

## Export Settings

### For Digital Presentations
- Format: PDF or native format (PPTX/KEY)
- Resolution: High quality (300 DPI)
- Fonts: Embedded
- File size: Optimize images if over 50MB

### For Print Handouts
- Format: PDF
- Layout: 2-3 slides per page
- Color mode: CMYK (for commercial printing)
- Resolution: 300 DPI minimum

### For Screen Sharing
- Format: PDF (for reliability)
- Resolution: 1920 × 1080
- Fonts: Embedded or outlined
- Test on target platform beforehand
