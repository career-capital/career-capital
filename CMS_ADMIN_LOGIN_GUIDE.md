# Content Management System - Admin Access Guide

## How to Log In to the CMS

### Step 1: Navigate to the Admin Login Page
- Open your web browser and go to: `https://your-website.com/admin`
- You'll see the Career Capital CMS login screen

### Step 2: Enter Your Credentials
- **Email**: Enter the email address that has been authorized for admin access
- **Password**: Enter your password
- Click the **"Sign In"** button

### Step 3: Access the CMS Dashboard
Once logged in, you'll see three main tabs:
- **Content Editor**: Edit all website page content
- **Testimonials**: Manage client testimonials and endorsements
- **Contact Submissions**: View and respond to contact form submissions

## Understanding Content Changes and Publishing

### Are Changes Live Immediately?

**Important**: When you save changes in the Content Editor, the behavior depends on the section's publish status:

#### Published Sections (marked "LIVE on site")
- **YES** - Changes are immediately visible to all website visitors after clicking "Save Changes"
- These sections have a green "LIVE on site" badge
- Any edits you make and save will instantly appear on the live website

#### Draft Sections (marked "DRAFT")
- **NO** - Changes are saved but NOT visible to website visitors
- These sections have a gray "DRAFT (not visible to visitors)" badge
- You can edit freely and save multiple times without affecting the live site
- Click the "Publish" button when you're ready to make the section live

### Best Practice Workflow

1. **For Minor Edits**: Make your changes and save directly if the section is already published
2. **For Major Changes**: Consider unpublishing the section first, make all your edits, preview them, then republish
3. **Always Save**: Click the "Save Changes" button after making edits - changes are NOT automatic

## Content Editor Overview

### Selecting a Page
At the top, you'll see buttons for each page (Home, About, Services, etc.). Click on a page to edit its content.

### Adding New Sections
1. Click the **"+ Add Section"** button
2. Choose from available templates:
   - **Hero Banner**: Large banner with background image and call-to-action buttons
   - **Icon Grid (3 columns)**: Three cards with icons, titles, and descriptions
   - **Call to Action**: Centered content with heading, text, and buttons
   - **Text Block**: Heading with multiple paragraphs
   - **Text Only**: Pure text content with multiple paragraphs
   - **Image + Text**: Side-by-side image and text layout

### Editing Section Content

1. Find the section you want to edit
2. Click **"Edit Content"** to open the editor
3. Make your changes to:
   - **Content Blocks**: Text, headings, images, icons
   - **Buttons**: Button text, links, and styles
4. A yellow banner will appear showing "You have unsaved changes"
5. Click **"Save Changes"** to push your edits to the website

**Important**: Changes will only be saved when you click the "Save Changes" button. Edits are NOT saved automatically.

### Managing Sections

**Publishing/Unpublishing**
- Click the **"Unpublish"** button to hide a section from visitors (turns it to draft mode)
- Click the **"Publish"** button to make a draft section visible on the live site

**Reordering Sections**
- Use the up/down arrow buttons (↑ ↓) to change the order sections appear on the page
- Changes to order are immediate

**Deleting Sections**
- Click the trash icon (🗑️) to permanently delete a section
- This action cannot be undone - you'll see a confirmation prompt

## Testimonials Management

### Adding a New Testimonial
1. Switch to the **"Testimonials"** tab
2. Click **"+ Add New"**
3. Fill in:
   - Quote
   - Author name (First Name, Last Name format)
   - Company
   - Testimonial type (Client or Professional Endorsement)
   - Tags (engagement type and topics)
4. Check **"Display on website"** to make it visible
5. Check **"Feature on home page"** to show it on the homepage (max 5 featured)
6. Click **"Add Testimonial"**

### Editing Testimonials
- Click the pencil icon (✏️) to edit
- Use the up/down arrows to reorder
- Click **"Hide"** or **"Show"** to control visibility
- Click **"Feature"** or **"Featured"** to toggle homepage featuring

## Contact Submissions

All contact form submissions appear in the **"Contact Submissions"** tab:
- View submitter name, email, organization, and message
- Change status: New → Read → Responded → Archived
- Click the email address to send a reply directly
- Delete submissions you no longer need

## Tips for Success

1. **Preview Before Publishing**: Make changes in draft mode first, then publish
2. **Save Frequently**: Click "Save Changes" after making edits
3. **Use Descriptive Headings**: Help visitors understand your content at a glance
4. **Optimize Images**: Use high-quality images but keep file sizes reasonable
5. **Test on Mobile**: Remember visitors view your site on phones and tablets too
6. **Logout When Done**: Click the "Logout" button in the top right when finished
