## Spacing System (8px base)

| Size | Value | When to Use |
|------|-------|-------------|
| XS | 8px | Tight spacing, related elements |
| S | 16px | Default spacing between elements |
| M | 24px | Sections within components |
| L | 32px | Between components |
| XL | 48px | Major section breaks |
| XXL | 64px | Page sections |

**Slides:**
- Title to body: 48-64px
- Between bullets: 24-32px
- Margins: 100px all sides

**Print:**
- Between paragraphs: 8-12pt
- Between sections: 24-36pt
- Page margins: 0.75"-1" minimum

## Layout Guidelines

### Presentations
- Max 6 lines of body text per slide
- 40-50% white space minimum
- Left-align text (not justified)
- Maximum 60% slide width for text

### Print
- Line length: 50-75 characters
- Line height: 1.5-1.7 for body text
- Widows/orphans: min 2 lines
- Bleed: 0.125" beyond trim

## Logo Usage

**Clear Space:** Height of letter "C" on all sides

**Minimum Sizes:**
- Print: 0.75" width
- Digital: 200px width

**Colors:**
- Light backgrounds: Deep Space Blue #0F2A44
- Dark backgrounds: True White #FFFFFF

## File Specs

### Print-Ready Files
- Format: PDF/X-1a or PDF/X-4
- Resolution: 300 DPI minimum
- Color mode: CMYK
- Fonts: Embedded or outlined
- Bleed: 0.125" all sides

### Presentation Files
- Format: PPTX, KEY, or PDF
- Aspect ratio: 16:9
- Resolution: 1920×1080px minimum
- Fonts: Embedded

## Quick Rules

✓ **DO:**
- Use Space Grotesk for headers
- Use Inter for body text
- Maintain generous white space
- Check color contrast (4.5:1 minimum)
- Use Navy for main headers
- Use Slate for body text

✗ **DON'T:**
- Use more than 2 font families
- Set body text smaller than 11pt (print) or 24pt (slides)
- Use pure black (#000000) for body text
- Justify text (use left-aligned)
- Overcrowd slides with text
- Use dark text on dark backgrounds

## Common Slide Layouts

**Title Slide:**
- 72pt title (centered)
- 36pt subtitle
- Logo bottom right

**Content Slide:**
- 48pt header (left-aligned)
- 28pt body (left-aligned)
- 4-6 bullets max

**Quote Slide:**
- 36pt italic quote (centered)
- 24pt attribution (centered below)

**Two-Column:**
- 48pt header
- Two equal columns, 60px gutter
- 28pt body text

- Use active voice
